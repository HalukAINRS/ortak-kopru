# Gerçek CLI ilerlemesi

Bu dizin Şaman'ın yeni oturumunda oluşacak kabul, kaynak erişimi, uygulama ve devam kayıtları içindir. Başlangıç paketi yalnız bu açıklamayı içerir; önceden doldurulmuş bir başarı veya hedef-CLI alındısı yoktur.

İlk gerçek okumanın ardından `DEVIR_ALINDI.json`; devam eden işler için `ACIK_ISLER_GUNCEL.md` oluşturulur. Gerçek işlem sonuçları iş kimliğiyle ilişkilendirilir. Özel kaynak yolları veya kimlik bilgileri açık Git'e eklenmez. Bu dizin manifestonun sabit dosya kapsamı dışındadır.
