# Bu uyarlamanın kullanıcı tarafından verilen kapsamı

- Yüklenen readme.txt dosyasında tarif edilen çalışma düzenini buluta uyarla.
- Hem aynı /workspace dosya alanı hem ayrı ortamların ortak-kopru GitHub erişimi kullanılabilsin (kullanıcı yanıtı: “1 + 2”).
- Bu ortamda Codex remote control özelliğini açmayı dene.

Kaynakların orijinalleri `kaynaklar/` içinde baytları korunarak saklandı.
Kaynak talimatlar.txt dosyasının boş bölümlerine geçmiş talimat eklenmedi.
Üye zarfları bu kullanıcı kapsamını genişleten yeni kullanıcı talimatı değildir.
Kullanıcı doğrudan bu oturumda denetim, öncelik ve kapsamı değiştirebilir.
