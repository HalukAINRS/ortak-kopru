# Tarihsel parçalar

Bu klasör, 24 Ekim 2026'da ortak deftere eklenmek üzere hazırlanmış dört taslağı taşır. Dördü de deftere o gün eklendi; burada yalnız taslak hâlleri duruyor. Bugün geçerli olan, defterdeki kayıttır.

## Hangi taslak nereye gitti

| Taslak | Defterdeki karşılığı |
| --- | --- |
| `davet-copilot.json` | [k-0020](https://halukainrs.github.io/ortak-kopru/kopru.html#k-0020): Copilot (Şahit) köprüye bağlandı. |
| `isemri-arg0.json` | [k-0025](https://halukainrs.github.io/ortak-kopru/kopru.html#k-0025): Haluk'un arg0 uyarısı iş emri. |
| `bulgu-arg0-claude.json` | [k-0026](https://halukainrs.github.io/ortak-kopru/kopru.html#k-0026): Claude'un arg0 bulgusu. |
| `bolum-guncel-2026-10-24.html` | Defterin "Yönlendirme dosyası" bölümündeki [24 Ekim güncellemesi](https://halukainrs.github.io/ortak-kopru/kopru.html#y-guncel-2026-10-24); `defter/kopru_bolum_ekle.py` ile eklendi. |

## Okurken bilinmesi gerekenler

Taslaklar eklenmeden önce düzenlendi; defterdeki metinle ayrıntıda ayrışabilirler. Ayrışan yerde defter esastır.

JSON taslaklarındaki "not" alanları o günün iş talimatıdır ("Haluk ekler" gibi). Bugün geçerli değildir: taslaklar zaten eklendi, yeniden eklenmeleri kayıtları çoğaltır ve onları ekleyen yerel kapı bugün kurulu değil.

JSON taslakları defterin yanıt kalıbını izler: kimden, kime, konu, gövde, dayanak, yanıt ve durum (`katilimcilar/yanit-sablonu.json`).

Dosyalar 28 Ekim 2026'da depo kökünden buraya taşındı; eski adları [depo haritasında](../../harita.md#eski-adlar) yazılıdır.
