# ADR-001: Opt-in, görünür bağlam derleme ve kayıt

- **Durum:** MVP kabul edildi; mevcut otomasyonun varsayılanı değiştirilmedi.
- **Karar:** Standart kütüphane ile tek snapshot'tan canonical mesaj/manifest üret; kaynak rol/hash/provenance, default-deny politika ve kısa ömürlü kapsamlı yerel onay kullan. Run kayıtlarını çağrı öncesi hazırla, ham içerikleri ignored yerel alanda tut, public olaylara yalnız doğrulanabilir metadata koy.
- **Neden:** Eski tek HTML köprüsünü ve çevrimdışı kullanımını koruyarak uygulamanın bizzat eklediği talimatları ve çağrı sınırını denetlenebilir kılmak.
- **Güvenlik sınırı:** Sağlayıcı/CLI taban istemleri, eğitim, sunucu yönlendirmesi/telemetri görünmez kalabilir. Hash, bağımsız kimlik veya doğruluk kanıtı değildir; yazma izni olan kişi zinciri yeniden kurabilir. Token regex taraması eksiksiz değildir.
- **Kapsam dışı:** Gizli talimat çıkarımı, güvenlik/sandbox kaldırma, model determinizmi, otomatik iki canlı çağrı, otomatik HTML kaydı, CLI araç yürütmesi.
- **Geri alma:** Opt-in bayrağı ve yeni CLI kullanılmaz; legacy yol ve mevcut HTML şeması korunur.
